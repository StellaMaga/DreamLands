# 얕은 꿈
1. 환경
	- 지형 : 정해진 것이 존재하지 않아 주관에 따라 각기 다른 모습으로 눈에 들어온다.
	- 기후 : 흐릿한 꿈 처럼 한치 앞도 안 보이는 짙은 안개가 껴 있다.
	- 자원 : 전 세계의 꿈이 모이는 만큼 꿈 속에 여러 정보와 지식 그리고 비밀이 존재한다.

2. 역사
	- 황금의 시대 : 신화의 시대, 이때는 인류가 존재 하지 않아 얕은 꿈 또한 존재하지 않는다.
	- 은의 시대   : 전설의 시대, 인류가 막 등장한다, 아직도 얕은 꿈은 존재하지 않는다.
	- 청동의 시대 : 혼돈의 시대, 인류는 살아남기 바빠서 꿈을 꿀 여유도 존재하지 않는다. 
	- 영웅의 시대 : 영웅들이 나타나 인류가 번성하고 꿈을 꾸는 자 또한 늘어나면서 얕은 꿈이 생겨난다.
	- 철의 시대   : 현대, 이제 얕은 꿈은 깊은 꿈과 맞먹는 힘을 가지게 되었다.

3. 세력
	- 결사 : 각기 다른 목적을 위해 모인 결사, 그렇기에 어중떵이가 많다.
	- 협회 : 몽상가들의 안전을 위해 모인 협회, 순수주의를 원칙으로 삼는다. 인공적인 몽상가는 받아들이지 않는다.
	- 회사 : 꿈 속에서 정보와 비밀 그리고 신비를 수집하는 회사, 당연히 금본주의.
	- 국가 : 공무원, 정체가 발견된 몽상가는 국가의 이름으로 강제 징용한다.
	- 신비 추종자: 신화의 시대를 그리워하며 신비를 찾아 얕은 꿈을 탐험한다.

4. 문화
	- 가치관 : 지독한 이기주의, 천상천하 유아독존, 오롯히 스스로만 존귀하다.
	- 관습   : 정체와 이름을 밝히지 않는다. 정체가 밝혀지면 현실에서 사로잡힐 수 있기 때문이다
	- 금기   : 알(꿈)을 부수지 않는다. 정체를 물어보지 않는다. 

5. 기술
	- 간섭, 거부, 의지: 몽상가가 다루는 힘, 꿈을 자유자재로 다루며 이를 통해 꿈 속을 돌아다닌다.
	- 신비 : 불가사이한 힘, 물리법칙을 벗어나 비현실 적인 일을 일으킨다.

6. 기타
	- 안개가 한치 앞도 안 보일만큼 자욱하게 펼쳐져 있다
	- 안개 너머 온갖 기기괴괴한 그림자가 눈에 들어온다
	- 유실물이 존재하는 장소는 안개가 밀려나있다.
	- 특정 테마가 모인 장소는 안개가 사라지고 완전히 다른 세상이 펼쳐진다.
	- 안개 바다 위에 있는 섬들?
	- 공간은 몽상가의 관점에 의해 고정된다
	- 고정할 자아가 흐려지면 끝없이 가라앉는다
