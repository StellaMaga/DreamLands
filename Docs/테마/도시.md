# [테마: 도시]
- 도시를 배경으로 만들어진 테마.
- 새벽, 정오, 황혼을 기점으로 배경이 바뀐다.
- 탈출 조건은 13턴을 넘기는 것이다.

# 페이즈
1. 새벽(7턴) : 평화롭고 희망찬 부분의 도시를 보여준다.
2. 정오(16턴): 강열하고 혼란스러운 부분의 도시를 보여준다.
3. 황혼(24턴): 정적이고 어두운 부분의 도시를 보여준다.
