# 테마
- 공통된 테마를 중심으로 만들어진 특수한 지형
- 많은 개념을 포함 할 수록 강한 억지력을 가진다.
- 한번 진입하면 조건을 달성하기 전까지 빠져나오지 못한다


# 문화
- 얕은 꿈은 인류의 꿈이 모인 공간이다.
- 테마는 공통된 테마의 꿈이 모인 공간이다.
- 그렇기에 같은 테마라 하더라도 여러 시간대의 건축물과 문화가 존재한다.
- 시간대 또한 과거부터 현대의 것, 동시에 사람들이 꿈꾸는 미래의 것도 존재한다.
- 여러 언어가 엉망진창으로 섞여 있기에 읽으려면 수많은 언어를 알아야 한다.


# 시스템
- 미니 이벤트: 해당 테마에 어울리는 여러 문구들
- 서브 이벤트: 해당 테마 안에 어울리는 일회성 이벤트
- 서브 테마 이벤트: 여러 이벤트를 담고 있는 서브 테마, 특정 조건 달성시 해당 테마로 이동한다
	- 예: [테마: 도시] 안에 있는 [서브 테마: 도서관] 진행중 [테마: 도시]에서 벗어나 [테마: 도서관]으로 이동
- 메인 이벤트: 해당 테마를 완전히 클리어 할 수 있게 하는 이벤트


# 난이도
- 테마를 오래 탐험 할 수록 해당 테마의 핵심에 다가간다
- 핵심에 다가갈 수록 난이도 또한 올라가며 이벤트도 달라진다.
- 메인 이벤트를 달성하고 핵심 까지 도달 할 경우 해당 테마의 코어를 손에 넣을 수 있다.


# 탈출 조건
- 각 테마 마다 해당 테마 탈출 조건이 다르다
- 예: 일정 턴 달성, 특정 서브 이벤트 달성, 특정 상태에 도달


# 클리어
- 메인 이벤트 달성 + 특정 턴수를 넘겨 핵심에 도달
- 보상: 해당 테마의 코어
- 코어는 강력한 효과를 가지고 있다.
