# 등장
길을 가다가 거지를 발견
거지는 앞을 못 보는지 붕대로 눈을 감고 있다.
거지 앞에는 그릇이 존재한다.
그릇 안에는 난생 처음 보는 진귀한 보물이 존재했다.

# 선택지
1. 진귀한 보물을 가져간다
	- 진귀한 보물을 눈에 담은 순간 타오르는 욕망과 질투를 참을 수 없었다.
	- 거지를 죽이고 보물을 취했다. 어떤 흔적도 남지 않았겠지.
	- 하지만 자리에 벗어나는 순간 보물은 손에 녹아 사라진다.
	- "스스로의 행운을 허공에 흩뿌리다니, 참으로 이상한 녀석이군"
	- 뒤를 돌아보자 거지는 사라져 있었다.
	- [행운 = 0]

2. 적선을 한다
	- 당신은 품에서 별빛을 조금 나줘준다.
	- 이유는 없다. 그저 자기만족에 불과하다.
	- "...당신의 앞날에 행운이 깃들길."
	- [별빛 - 7][행운 + 7]


3. 지나간다
	- 당신은 남의 것을 가져갈 몰혐치한도 아니지만
	- 누군가에게 연민을 베풀 여유도 존재하지 않기에 그저 지나간다
	- 아무런 일도 일어나지 않는다.
