# 이성	: 꿈과 현실을 인지하는 능력

# 스킬	: 꿈 속에서 얻을 수 있는 신비의 편린.

# 아이템	: 몇몇 아이템은 저주를 품고 있다.

# 트라우마
	- 간섭(의지 + 정신력) : 꿈의 내용을 변경하는 힘, 작게는 사소한 이야기를 바꾸지만 끄게는 꿈의 내용을 완전히 바꿀 수도 있다.
	- 거부(의지 + 이성)   : 꿈의 규칙을 거부하는 힘, 불합리한 규칙을 막거나 적의 공격으로 부터 스스로를 지킨다
	- 탐지(정신력 + 이성) : 꿈의 정체을 파악하는 힘, 꿈의 근원부터 어떻게 이야기가 흘러가는지 알 수 있다.
